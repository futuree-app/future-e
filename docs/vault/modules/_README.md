# modules/

Une page par surface produit : Territoire, Logement, Santé, Mobilité, Métier, Projets,
Comparateur. Chaque page documente l'objet du module, ses sources de données, ses
spécificités de doctrine, et renvoie aux décisions liées (adr/, arbitrages/).

## Pages

- **`territoire.md`** — frontière éditoriale : Territoire pose le décor, les autres modules
  le traduisent dans la vie de l'utilisateur (la page module complète viendra ensuite).

Les six autres pages (Logement, Santé, Mobilité, Métier, Projets, Comparateur) restent à
écrire à la phase modules.
