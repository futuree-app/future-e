# Arbitrage : pas de module Loisirs autonome

- **Date** : 2026-04-18
- **Source** : journal des décisions produit.

## Option étudiée

Un module Loisirs à part entière (ski, surf, randonnée et leur évolution climatique).

## Décision

**Pas de module autonome.** Les loisirs sont redistribués dans Quartier/Territoire et Santé.

## Pourquoi

Le sujet est réel mais ne porte pas une surface produit entière : il se lit mieux comme
facette d'un territoire (ce qu'on peut y faire) et de la santé (pratiques en extérieur,
chaleur). Un module dédié aurait dilué l'offre sans masse critique de données propres.
