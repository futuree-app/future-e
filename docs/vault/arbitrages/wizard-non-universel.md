# Arbitrage : le wizard reste attaché à « commune connue »

- **Date** : printemps 2026
- **Source** : `/memory/parcours_doctrine.md`.

## Option étudiée

Rendre le wizard (questionnaire de profil) universel, disponible à toutes les portes
d'entrée, y compris après une découverte de commune par le comparateur.

## Décision

**Le wizard reste attaché au parcours « commune connue ».** Il n'est pas universel.

## Pourquoi

Le wizard croise un profil de personne avec un INSEE unique. Le brancher après une
découverte casserait le contrat narratif (on a promis une exploration, pas un re-questionnement),
et croiserait mal un profil avec un lieu que l'utilisateur n'a pas encore choisi.
