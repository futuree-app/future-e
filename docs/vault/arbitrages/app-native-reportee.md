# Arbitrage : pas d'application native la première année

- **Date** : avril 2026
- **Source** : journal des décisions produit.

## Option étudiée

Une application mobile native dès le lancement.

## Décision

**Reportée.** Une PWA suffit pour l'année 1.

## Pourquoi

Coût de développement et de maintenance disproportionné pour un projet solo au démarrage,
sans bénéfice prouvé sur l'usage (lecture longue, sessions de décision, pas d'usage
quotidien). La PWA couvre le besoin mobile à coût marginal.
