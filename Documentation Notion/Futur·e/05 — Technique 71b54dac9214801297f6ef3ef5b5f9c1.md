# 05 — Technique

[05.1 — Journal des pushes et mises en ligne](05%20%E2%80%94%20Technique/05%201%20%E2%80%94%20Journal%20des%20pushes%20et%20mises%20en%20ligne.md)

## Ce que couvre cette section

- le mode de déploiement actuel
- l’historique des pushes visibles dans Git
- les principaux chantiers déjà sortis sur `main`
- les points de vigilance pour suivre la production proprement

## État actuel du workflow

- branche principale : `main`
- mode de livraison : push direct sur `origin/main`
- granularité actuelle : petits commits successifs, souvent par chantier
- déploiement : la production suit `main`
- pas de branches de release ni de tags de version pour l’instant

## Limite du suivi actuel

Le dépôt permet de retrouver l’historique des commits, mais pas encore un journal éditorialisé des mises en ligne.  
Le document 05.1 sert à combler ce manque : il regroupe les pushes en séquences compréhensibles, avec ce qui a réellement changé côté produit.

## Recommandation de suivi à partir de maintenant

Pour chaque mise en ligne notable :

1. garder un commit par chantier quand c’est possible
2. pousser sur `main`
3. ajouter une ligne dans 05.1 avec :
   - date
   - commit(s)
   - chantier
   - impact visible
   - éventuelle migration / configuration externe
